## Design Invariants

- Capture immutable GH (history), LM (latest input/messages), OC (authoritative overall context), stage-specific I (instructions), and plan as reusable typed variables. Keep them separate from existing string workflow variables.
- Separate scene intent, arbitrary ordered presentation beats, and execution dependencies. Do not impose a narration/action/subaction template.
- Each requested creative component gets its own LLM call with selected inputs. Store exact input/output revisions, provenance and retention policy; reference binary assets rather than duplicating base64.
- Lock actors, recipients, owners, accounts, amounts and destinations before writers run. Generated prose cannot change authority or become observed fact by default.
- Compose the visible reply deterministically from actual drafts, artifacts and receipts. No final giant JSON-writing LLM call.
- Reuse the existing validated action executor. Phone/RP projections share receipts, not duplicate effects. Cancellation, uncertain outcomes and committed-operation boundaries remain explicit.
- Compact structured plans may still use constrained schemas. Correction belongs before effects, primarily at plan and individual-content validation. Existing large-envelope support remains a compatibility path.
