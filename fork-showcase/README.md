# RPGraph fork showcase

A standalone, dependency-free presentation comparing upstream RPGraph Studio v0.5.3 with the Sloppified fork.

Open `index.html` directly, or serve the repository root so the included MatchMe preview image resolves:

```powershell
npx vite --host 127.0.0.1
```

Then open `/fork-showcase/`. Use the arrow keys, on-screen controls, or a horizontal swipe to move between slides.

The repository change counts were measured from `upstream-inspect/main...main` on 2026-09-19.
