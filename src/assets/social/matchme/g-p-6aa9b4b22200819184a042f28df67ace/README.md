# MatchMe
Open matchme.html directly in a browser. CSS, JavaScript, SVG icons and generated moon/cloud artwork are embedded; no network or install required. assets/moon-clouds.png is the separate reusable artwork.

Local interactive prototype: photo uploads (3 maximum, 10 MB each), preferences, bio counter, interest chips, validation and success dialog. Character album is an integration placeholder. No server storage or account creation.

Visual review: compared the generated concept against preview-mobile.png with view_image. Checked heading/brand, plum-and-pink palette, fanned photo cards, field hierarchy, selected chips, and primary action. Visible starting copy matches the concept. Intentional adaptations: system Georgia/Arial typography, newly generated moon artwork, narrower responsive chips, and a centered desktop shell. Mobile screenshot is 390px wide rather than the concept's 870px raster width. Mobile overflow found and fixed. Browser checked at desktop size and mobile size. Built-in browser failed during file chooser; Playwright Chromium fallback verified photo upload and success dialog. No horizontal overflow at 390px.

Artwork generated with built-in Image Gen. Prompt: Portrait 3:4 background artwork for a romantic fictional-character dating app photo upload card; dark muted aubergine, dusty mauve crescent moon, three tiny pink four-point stars, layered rounded plum clouds along the bottom, restrained flat illustration with subtle grain, no text, UI, border, frame or photography.
